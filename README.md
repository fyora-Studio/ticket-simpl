# Fyora Studio Ticket System — V2.2 Lite

نظام تكتات Discord بـ Node.js و discord.js v14، مع اتصال صوتي دائم وحفظ محلي للصور.

## التشغيل
- Node.js 20 أو أحدث.
- ثبّت الحزم: `npm install --omit=dev` (مطلوب بعد تحديث V2.2: يضيف دعم تشفير DAVE للفويس)
- انسخ `.env.example` إلى `.env` وضع توكن البوت في `DISCORD_TOKEN`.
- أمر التشغيل: `npm start`
- أمر لوحة الإدارة: `!ticket`
- فعّل Message Content Intent وGuild Voice States Intent من Discord Developer Portal.

## لوحة الإدارة
- لوحة الإدارة مبنية على Components V2.
- إنشاء أنواع التكت وتعديلها وحذفها وتحديد الرتب المخولة.
- رفع صور البانل والخط وصور كل نوع تكت من الجوال كمرفقات. الصور تُنزّل وتُحفظ داخل `data/images` حتى لا تعتمد على روابط Discord المؤقتة.
- عند اختيار عرض صورة البانل داخل Embed، يطلب البوت نصاً يظهر أعلى الصورة.
- نشر لوحة التكت يطلب اختيار روم نصي محدد، ولا ينشر تلقائياً في روم لوحة الإدارة.
- صورة الخط تُرسل مع البانل كفاصل، وتظهر كذلك مع رسالة التكت عند توفرها.

## الدعم الصوتي
- اختيار قناة فويس يجعل البوت يدخل القناة فعلياً ويبقى متصلاً بها وهو صامت ومُصمّت.
- يعيد البوت الاتصال بالقناة المحددة بعد إعادة تشغيله.
- يحتاج البوت صلاحية Connect في القناة، مع تفعيل Guild Voice States Intent.
- إزالة التعيين تفصل البوت من قناة الصوت.

## التكتات
- لوحة فتح التكتات تستخدم قائمة منسدلة.
- يمنع فتح أكثر من تكت مفتوح واحد للشخص في السيرفر.
- أزرار الاستلام والإغلاق والحذف، مع صلاحيات الرتب المخولة.
- صورة النوع تُرفق في كل تكت جديد، وصورة الخط تُرفق كفاصل.
- Transcript نصي إلى روم السجلات عند الحذف أو الحذف التلقائي.

## صلاحيات البوت
View Channels, Send Messages, Read Message History, Manage Channels, Attach Files, Embed Links, Manage Roles, Connect. رتبة البوت أعلى من رتب الدعم التي يديرها.

## التخزين والأداء
- JSON داخل `data/tickets.json`، والصور داخل `data/images`.
- لا تحذف مجلد `data` عند التحديث، لأنه يحتوي الإعدادات والصور.
- لا تستبدل `.env` عند التحديث.
- discord.js و @discordjs/voice هما اعتمادا التشغيل.

## فحص الصياغة
`npm run check`

اختبار محلي: `npm test` (لا يتصل بسيرفر Discord حقيقي).
